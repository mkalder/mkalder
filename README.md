## Current focus: nlm

I'm building and training a small GPT-like language model to generate
short, simple English children's stories.

The goal is to understand the full path from tokenization, embeddings
and attention to the backward pass, training and evaluation.

I'm documenting the process in an accompanying project book:
implementation choices, experiments, failures and known limitations.

Training is in progress. Next comes evaluating the generated stories
for coherence, simple language and recurring failure patterns.

A lower validation loss is a useful signal—not proof of good stories.
